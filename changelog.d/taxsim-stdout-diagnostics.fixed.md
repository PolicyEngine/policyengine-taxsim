TaxsimRunner no longer turns diagnostic lines that taxsimtest writes to stdout (such as the six `d2` lines the 20260521 macOS build prints before some elderly Utah records) into rows with a NaN taxsimid, or fails when they come before the header. It returns one row per record, keeps the other lines in `TaxsimRunner.stdout_diagnostics` under the taxsimid of the row that follows them, and logs a warning, plus one naming any submitted record that came back without a row. `policyengine-taxsim taxsim --taxsim-path` now runs the given binary instead of failing with `'str' object has no attribute 'exists'`.
