`policyengine-taxsim --version` prints the policyengine-taxsim, policyengine-us and policyengine-core versions and the bundled TAXSIM binary's build. `--provenance PATH` (on the stdin command and the `policyengine`, `taxsim` and `compare` subcommands) writes those versions, the TAXSIM binary's SHA-256, the run's options, SHA-256 hashes of its input and output, and every installed package version to a JSON file, leaving the TAXSIM-format output unchanged.
