R: `policyengine_calculate_taxes()` now computes tax years before 2021 with the bundled TAXSIM-35, as the command line does, where it used PolicyEngine for every year. Results for pre-2021 records therefore change; results for 2021 and later do not. Pass `engine = "policyengine"` to compute every year with PolicyEngine as before. Rows now come back in input order, and data that mix years before and after 2021 have both engines' columns. `setup_policyengine()` now installs the policyengine-taxsim release that matches the R package from PyPI, where it installed the `main` branch from GitHub with `--upgrade`, and takes `policyengine_taxsim_version`, `wheel_dir` (install from a folder of wheels, with no network access) and `python`. The R package is version 0.2.0.
